設計メモ: docs/architecture.md(「テスト」)
前提: `origin/feature/vite-mpa` から `feat/37-e2e` を切る。#31(島)、#32(永続化)、#33(3D)はマージ済み。#38(CI)が並行して `.github/workflows/ci.yml` を作るので、この Issue では CI の YAML を触らず、E2E のジョブ定義は PR 本文に書いて #38 のマージ後に別コミットで足す

## 目的

ビルド済みの `dist/` を実際のブラウザで開き、MPA でしか確かめられない振る舞い(ページをまたぐ状態、島の動作、JS の配信範囲、遅延読み込み)を固定する。

- `web/package.json`: devDependencies に `@playwright/test`。scripts に `test:e2e`(`playwright test`)、`test:e2e:ui`。他の行は触らない

- `content/en/e2e-*.json`、`content/ja/e2e-*.json`(新規、`published: false`): E2E 用の固定ページ。ビルド時に `E2E=1` のときだけ published として扱う仕組みが要るなら、`routes.ts` ではなく `prerender.mjs` の環境変数で `published: false` のページも出す(`PRERENDER_ALL=1`)。この変更は `web/scripts/prerender.mjs` への最小の追加で、`npm run check` はページ数の対応で見ているので壊れない。README に書く

## 設定

- `playwright.config.ts`: `webServer` は `npm run build && npm run preview`(`PRERENDER_ALL=1`)。`baseURL` は `http://localhost:4173`。projects は `chromium`(1280×800)と `mobile-chromium`(Pixel 5 相当、幅 375px、`tests/mobile/` だけ)。CI では `retries: 1`、`trace: on-first-retry`。ローカルでは `retries: 0`
- Chromium の起動引数に `--use-angle=swiftshader --enable-unsafe-swiftshader` を付ける(ヘッドレスで WebGL を有効にするため)
- `page.route("**/*")` で、`localhost` 以外へのリクエストを失敗させる fixture を全テストに掛ける(外部リソースの規定を E2E でも固定する)
- `WIKI_BASE=/keio/` でビルドして走らせる project(`chromium-base`)も1つ作る。`preview` は `--base` を読まないので、`vite preview` の `base` 設定か、`dist/` を `/keio/` 配下に置いた静的サーバー(`npx serve` ではなく Node の `http` で数行)で配信する。どちらにするかは実装者が決めて README に書く

## テスト

`tests/` 以下、1ファイル1テーマ。

1. `nav.e2e.ts`: ヘッダーのナビから全ページ(published なもの)に到達できる。各ページの `<title>` と `<h1>` がある。`aria-current="page"` が現在のページに付く
2. `locale.e2e.ts`: `/members/` で JA をクリックして `/ja/members/` に移ると、`localStorage.getItem("wiki:locale")` が `"ja"`(JSON の文字列)になっている。相手の言語に無い slug のページでは切り替え先が `/ja/` になる(E2E 用の en だけのページを使う)
3. `islands.e2e.ts`: `/` と `/model/` 相当のページで `<script>` が無く、JS のリクエストが0件。`/members/` で `data-island-mounted` が付き、カードをクリックするとモーダルが開き、Esc、オーバーレイのクリック、閉じるボタンのそれぞれで閉じる。`/members/` のリクエストに `model-viewer` のチャンクが無い
4. `model-viewer.e2e.ts`: E2E 用の 3D ページ(`models` に `/models/sample.glb`)。ビューポートを低くして、ビューアが画面外のときは `model-viewer-*.js` と `.glb` のリクエストが0件、`scrollIntoViewIfNeeded` の後に両方が1件ずつ来て、`model-viewer` の `loaded` が true になる。`addInitScript` で `getContext` を潰した場合は poster の `img` が出て、チャンクも `.glb` も0件
5. `prose.e2e.ts`: `prose-sample`(#29 のサンプル。#29 が未マージなら、このテストは `test.skip` にして理由を書く)で、Figure カード、Note、KaTeX が描画される(`.katex` の要素が存在し、フォントが読まれている)
6. `mobile/sidebar.e2e.ts`: 375px で上部バーが出て、トグルでナビが開閉する。開いた状態で全ページへのリンクがある
7. `visual.e2e.ts`: `/`、`/members/`、`prose-sample` を 1280px と 375px で `toHaveScreenshot`。`auto-rotate` する 3D は撮らない。アニメーションは `animations: "disabled"`。基準画像はこの PR で生成してコミットする(Linux の CI と macOS で字形が違うので、CI で生成した画像を基準にする方針。ローカルでは `--update-snapshots` で上書きせず、`maxDiffPixelRatio: 0.02` で緩める。READMEに書く)
