Engineering

Design — Build — Test — Learn

細菌の極に接着分子を偏在させ、細胞間接着に「方向」を与える

このページの読み方

本ページは、プロジェクトを通じて回した Design–Build–Test–Learn（DBTL）サイクルをまとめたものである。実験の時系列そのものではなく、「何を仮説として設計し、作り、試し、そこから何を学んで次にどう変えたか」という反復の筋を追う。

検証を要素ごとに5つのサイクルへ分けた。各サイクルは冒頭に仮説と成功基準を掲げ、複数の反復（Iteration）から成る。

取得データと図は Results を、詳細な手順は Notebook を参照。

概要 — 5つのサイクル

本プロジェクトは「接着分子を細胞の一方の極に集中させ、細胞間接着に方向を与える」ことを目指した。この目標は、性質の異なる複数の要素が直列に機能して初めて達成される。そこで検証を要素ごとに分け、それぞれを独立した DBTL サイクルとして回した。

# サイクル 問い 反復 到達点
1 局在の観察系 極局在を、細胞と対応づけて判定できるか 6 アガロースパッド法（最終1%）と同一視野撮影で、生菌の極局在を観察できる系を確立
2 接着と直交性 設計した Ag/Nb ペアで特異的に接着するか 4 対応ペアのみ沈降。二色蛍光でヘテロ接着を直接証明
3 クローニング技術 多断片コンストラクトを安定して構築できるか 4 DpnI 処理の延長と断片量の増量で歩留まりを改善し、Intimin シリーズを構築
4 発現量の定量 IPTG 濃度と発現量の関係を読めるか 4 in-gel 蛍光の希釈率と OD 補正を確立し、濃度依存性を検出
5 画像解析 局在を目視でなく数値として判定できるか 4 Omnipose でセグメンテーション。切り抜き判定で片極から両極への移行を数値化

サイクルどうしの関係

これら5つは独立ではなく、互いに供給し合いながら回った。サイクル3（クローニング）がコンストラクトを供給し、それをサイクル1（観察）・サイクル2（接着）・サイクル4（定量）が試す。サイクル1が整えた観察系の上に、サイクル5の画像解析が乗る。

逆方向の流れもあった。接着実験で「どの菌とどの菌が結合しているか識別できない」という学びが、サイクル3に「蛍光標識した Intimin を作る」という新しい設計要求を返している。DBTL は各サイクルの中で閉じるだけでなく、サイクルをまたいで循環した。

設計段階のプライマー設計

各サイクルの Design フェーズでは、iVEC3 法の原理に則ったプライマー設計を行った。iVEC3 法では、ベクターとインサートの末端に互いに相補する配列（相同配列）を持たせ、大腸菌自身の組換え能で環状化させる。したがってプライマーの5'側に、繋ぎたい相手の配列を必要な長さだけ付加する設計が中心になる。Ag2 を Nb2 に差し替えるプライマーや、Intimin の LysM 領域を CoilR で置換するプライマーなど、接合部が複雑な構築では、この相同配列の設計が成否を分けた。

サイクル1 — 極局在の観察系

見えなければ、何も主張できない

プロジェクトのすべての主張は、蛍光顕微鏡で「タンパク質が極に局在している」ことを示せるかにかかっている。ところが観察系は初めから機能したわけではなく、6回の反復を経て、ようやく生きた大腸菌の極局在を細胞と対応づけて観察できるようになった。
仮説 発現量に応じて PopZ が単極から両極へ切り替わる。適切な標本作製と観察条件を整えれば、その局在を細胞ごとに判定できる。
成功基準 明視野像と蛍光像を同一視野で重ね、1細胞あたりの蛍光フォーカスを数えて単極／両極を判定できる標本作製・観察条件を確立すること。

反復1 — 初観察：蛍光は見えるが局在は判定できない

DESIGN BUILD TEST LEARN
発現量で PopZ の単極から両極への切り替わりが決まるはず（Lin 2021）。mCherry-PopZ を誘導して極局在を見る。 pTac-mCherry-PopZ を構築し、IPTG で誘導。菌液をスライドガラスに載せて観察。 蛍光は見えたが、明視野像を別視野で撮ったため細胞と対応づけられない。菌が密集し個体を分離できない。 「蛍光が見える」だけでは局在を主張できない。細胞と対応づく観察系が要る。

反復2 — 培地の自家蛍光を除く

DESIGN BUILD TEST LEARN
同一視野で明視野と蛍光を撮り、重ね合わせる。背景を下げるため培地を除く。 MQ 水で3〜4回洗って培地を置換し、乾燥固定して観察。 乾燥法である程度局在は見えたが、菌が死ぬ・変形するため判定が不安定。 培地の自家蛍光（特に緑チャネル）が弱い msfGFP を埋める。ただし乾燥固定は生菌観察に使えない。

反復3 — 生菌固定：アガロースパッド法へ

DESIGN BUILD TEST LEARN
生きたまま単層に固定できるアガロースパッド法を試す。 2×LB と低融点アガロースを混合したゲルパッド上に菌液を載せる。 生菌のまま観察でき、蛍光も確認できた。ただしアガロース濃度で見え方が変わる。 アガロースパッド法は生菌観察に適する。濃度の最適化が次の課題。

反復4 — アガロース濃度の最適化

DESIGN BUILD TEST LEARN
最終アガロース濃度を 1% / 1.5% / 2% で振り、最も見やすい条件を決める。 3濃度のゲルパッドを作製し、同じ菌液で比較。 1% で片側局在を確認。1.5%・2% は夾雑物が目立ち、菌の判別が難しい。 最終1%が最適。以降の観察はすべてこの条件に統一する。

反復5 — 観察チャネルの取り違え

DESIGN BUILD TEST LEARN
DivIVA-msfGFP の局在を観察する。 誘導した DivIVA を蛍光顕微鏡で観察。 msfGFP なのに mCherry チャネルで観察していた。それでも「傾向」が見えたのは夾雑物が偶然光っていた可能性。 蛍光タンパク質とチャネルの対応を必ず確認する。非特異的な蛍光を目的シグナルと誤認しない対照が要る。

反復6 — 誘導時間：過渡期を避ける

DESIGN BUILD TEST LEARN
IPTG 濃度と局在の相関が見えないのは誘導の過渡期に観察していたためと考え、十分時間を置く。 IPTG 添加後 8時間〜一日おいて誘導を定常化させ、正しい GFP チャネル・1% パッドで観察。DivIVA は MQ 洗浄も併用。 定常化した状態での相関を評価（結果は Results 参照）。 観察系の変数は「濃度・菌体量」だけでなく「誘導からの経過時間」も効く。過渡応答を避ける運用を標準化。

このサイクルで確立したこと

  • 2×LB＋最終1%低融点アガロースパッド法により、生きた大腸菌を単層に固定して観察する。
  • 明視野像と蛍光像を同一視野で取得し、重ね合わせて細胞とシグナルを対応づける。
  • 蛍光タンパク質に対応した励起・検出チャネルを選び、発現量が低い場合は MQ 洗浄で培地の自家蛍光を除く。
  • IPTG 誘導は過渡期を避け、十分に時間を置いてから観察する。

サイクル2 — 接着と直交性

沈まない、から、混ざっていると言えるまで

接着モジュールそのものが機能し、かつ複数の Ag/Nb ペアが混線せず直交的に働くかを検証した。沈まない → 条件を上げて沈降を確認 → 蛍光標識コンストラクトを新規構築 → 二色と対照で特異性を証明、という4回の反復で進み、最終的に定量・目視・二色蛍光・対照という4つの独立した読み出しで接着の特異性を裏づけた。
仮説 Intimin に提示した対応する Ag/Nb を持つ細胞どうしのみが特異的に接着し、凝集して沈降する。非対応ペアは接着しない。
成功基準 対応ペアの混合で上清 OD が単独平均を明確に下回り、非対応ペアでは下回らないこと。さらに二色蛍光で凝集塊内に緑と赤の細胞が混在すること。

反復1 — 滴定して沈降を見る：しかし沈まない

DESIGN BUILD TEST LEARN
Intimin は過剰発現で提示が渋滞し逆に接着しない（Glass 2018）。最適発現量を IPTG 滴定で探し、沈降アッセイで接着を見る。 Ag2・Nb2 を IPTG 0〜1000 µM で誘導し、同濃度どうしを 1:1 混合して静置。単独を対照に置く。 全濃度で沈降が見られなかった。OD 測定はまだ行っていない。 全濃度で沈まないなら発現量以外に原因がある。菌体密度・反応時間の不足を疑う。

反復2 — 反応時間と菌体密度を上げ、蛍光を使わず沈降で見る

DESIGN BUILD TEST LEARN
接着には十分な菌体密度と反応時間が要ると考え、条件を上げて沈降そのものを追う。この段階のコンストラクトは蛍光タンパク質を持たないため、目視と OD のみで判定する。 OD 1.2 以上まで培養し Ag2/Nb2 を各 2 mL 混合。10分おきに OD を測定し、8時間程度まで反応時間を延長して経時変化を追う。 混合時のみ OD が単独平均を大きく下回った。低下は 40〜50分から明確になり、その後頭打ちになる。 接着は起きている。前回沈まなかったのは菌体密度と反応時間の不足だった。ただし「何が沈んだか」は目視では分からない。

反復3 — 蛍光タンパク質を融合した新しいコンストラクトを作る

DESIGN BUILD TEST LEARN
凝集塊の中身を確かめるには細胞自体を蛍光で識別する必要がある。ところが既存の Intimin コンストラクトは蛍光タンパク質を含んでいないため、新たに融合体を設計する。 Intimin-Ag2 に msfGFP（緑）、Intimin-Nb2 に mCherry（赤）を融合したコンストラクトを新規に構築（サイクル3の技術で作製）。 標識した菌体が蛍光顕微鏡で個体として識別できるようになった。 観察の要求がコンストラクト設計に跳ね返った例。これで次の二色観察が可能になった。

反復4 — 二色蛍光と非対応ペアで、特異性を直接示す

DESIGN BUILD TEST LEARN
標識株を使い、凝集塊の内部で緑と赤が混在するかを見る。あわせて非対応ペアを対照に置き、直交性を確かめる。 Ag1/Nb1 を加えた4ペア（対応：Ag1-Nb1, Ag2-Nb2／非対応：Ag1-Nb2, Ag2-Nb1）を同濃度どうしで混合し、OD 経時測定と二色観察を行う。 Ag1-Nb1・Ag2-Nb2 のどちらの対応ペアでも沈降が見られ、OD が低下した。非対応ペアは横ばい。二色観察で凝集塊内に緑と赤の細胞が混在していることを確認。 2組の対応ペアがいずれも沈降し、非対応ペアは沈降しない。接着は特異的かつ直交的である。二色混在は「同種の自己凝集ではなくヘテロ接着」であることの直接証拠になる。

反復4の意義 — 4つの独立した読み出しの一致

吸光度の低下（マクロな定量）、目視の沈殿、二色蛍光による細胞レベルの識別、そして非対応ペアという対照。これら4つが一致したことで、「何かが沈んだ」ではなく「Ag2 細胞と Nb2 細胞が特異的に結合した」と複数の角度から言える。

また、シーケンスで Intimin に一塩基変異が見つかっていたが、接着機能が保たれたことで「機能するなら直さず進める」という判断が正しかったことも確認できた。

残された課題

Ag1 は培養段階から自己凝集する傾向が見られたため、Ag1 を含むペアの OD 低下には自己凝集の寄与が混ざっている可能性が残る。ただし Ag2 は培養時の自己凝集がなく、Ag2-Nb2 系では二色混在まで示せているため、結論は Ag1 の挙動に依存しない。今後は単独株の経時 OD を並走させて自己凝集分を差し引くこと、および 3×3 の完全な直交性マトリクスを構築することが課題である。

サイクル3 — クローニング技術

鋳型をいかに取り除くか

サイクル1・2の裏で一貫して回っていたのが、コンストラクトを安定に作るための技術サイクルである。中心にあったのは**「鋳型プラスミドの残存」**という一つの問題で、これに複数のアプローチを重ねた。iVEC3 法はベクターを線状に増幅してインサートと組換えるが、増幅の鋳型に使った元プラスミドが残っていると、それがそのまま形質転換されて偽陽性コロニーになる。
仮説 構築失敗の主因は鋳型プラスミドの残存である。DpnI 処理を十分に行い、必要に応じて断片量や培養条件を調整すれば、目的のアセンブリ体が得られる。
成功基準 コロニーPCR で目的サイズの挿入を持つ陽性コロニーが安定して得られ、「元プラスミドのみ」の偽陽性が十分に減ること。

反復1 — msfGFP のみが出る：鋳型の残存を疑う

DESIGN BUILD TEST LEARN
pTac-msfGFP ベクターを線状に増幅し、SpmX・DivIVA と組む。 ベクターを PCR で増幅し、DpnI 45分処理のうえ iVEC3。 インサートが入らず、元ベクターと同じ「msfGFP のみ」のプラスミドしか得られなかった。 増幅した断片ではなく、鋳型に使った元プラスミドがそのまま形質転換されている疑いが濃い。DpnI が鋳型を切りきれていない。

反復2 — DpnI 処理を延長する

DESIGN BUILD TEST LEARN
鋳型を確実に分解するため、DpnI の処理時間を延ばす。 DpnI 処理を 45分から 60分に延長し、同じ構築を再度 iVEC3。 SpmX・DivIVA の当たりが取れた。ただし「msfGFP のみ」に相当する下側バンドも依然として残る。 DpnI 処理時間は歩留まりを直接左右する。ただし延長しても鋳型の混入がゼロになるわけではなく、複数コロニーから当たりを選ぶ運用が要る。

反復3 — うまくいかないときは PCR 産物量を増やす

DESIGN BUILD TEST LEARN
Intimin-Nb2 では iVEC3 自体がうまくいかずコロニーが得られなかった。組換えの機会を増やすため、投入する断片量を上げる。 ベクター・インサートの PCR 産物を各 2 µL から 3 µL に増量して iVEC3。 コロニーが得られ、Nb2 特異的プライマーで陽性クローンを確認できた。 アセンブリが起きない場合は、断片の絶対量を増やすことが有効。DpnI とは別の、独立した調整軸である。

反復4 — 培養条件を振る：室温で長く置く

DESIGN BUILD TEST LEARN
大腸菌内での組換えと生育に時間が要る可能性を考え、培養条件そのものを振る。 プレートを2枚に分け、37 ℃・16時間と室温・2日間で培養して比較。あわせて DpnI 処理後の PCR 産物を室温で一日置き、鋳型の分解を進めた。 37 ℃・1日でコロニーが得られた。室温・長時間との間でコロニー数に大きな差はなかった。 コロニーが取れなかった主因は培養条件や毒性ではなく、鋳型残存とアセンブリ効率の側にあると切り分けられた。

このサイクルで確立したこと

  • iVEC3 法の歩留まりを決める最大の要因は DpnI 処理である。処理が不十分だと、鋳型に使った元プラスミドがそのまま形質転換され、偽陽性コロニーとして現れる。処理時間の延長（45分→60分）が当たりを取る鍵になった。
  • アセンブリが起きずコロニーが得られない場合は、PCR 産物の投入量を増やす（各 2 µL→3 µL）。DpnI とは独立した調整軸として有効だった。
  • 培養条件（37 ℃・16時間／室温・2日間）を振って比較した結果、コロニーが得られない主因は培養条件や Intimin の毒性ではなく、鋳型残存とアセンブリ効率の側にあると切り分けられた。
  • 挿入の確認は、ベクター側プライマーとインサート特異的プライマーの両方で行う。サイズの近い構築（Ag2 と Nb2 など）は同一ゲルで対照と並べる。

サイクル4 — 発現量の定量

飽和と検出限界のあいだを探す

局在や接着を「発現量で制御できるか」を問うには、まず発現量そのものを測れなければならない。融合タンパク質の in-gel 蛍光で IPTG 濃度と発現量の関係を読もうとしたが、適切な希釈率にたどり着くまでに4回の反復を要した。
仮説 IPTG 濃度を上げると融合タンパク質の発現量が増え、その差は in-gel 蛍光のバンド強度として読み取れる。
成功基準 菌体量を揃えたうえで、IPTG 濃度に対してバンド強度が単調に変化し、濃度依存性を判別できること。

反復1 — 原液のまま：飽和して差が見えない

DESIGN BUILD TEST LEARN
破砕液をそのまま SDS-PAGE にかけ、in-gel 蛍光で発現量を比較する。 PopZ・SpmXΔC・DivIVA を IPTG 誘導・破砕し、原液をアプライ。 蛍光が強すぎて飽和し、IPTG 濃度による差が見えない。 シグナルが飽和すると濃度差が潰れる。希釈して検出レンジに収める必要がある。

反復2 — 20倍希釈：今度は薄すぎる

DESIGN BUILD TEST LEARN
飽和を避けるため大きく希釈する。 破砕液を 20倍希釈してアプライ。 バンドがほとんど消えてしまい、やはり読めない。 希釈しすぎると検出下限を割る。発現量に応じた適切な希釈率がある。

反復3 — 菌体量を揃える

DESIGN BUILD TEST LEARN
バンド強度が発現量の差か菌体量の差か区別できていない。破砕前に菌体量を揃える。 破砕前に各サンプルの OD を測定し、菌体量を揃えてから処理。 OD は条件間で約1割以内に揃い、バンド差を発現量差とみなせる前提が整った。 定量には菌体量の正規化が不可欠。OD 補正を標準手順に組み込む。

反復4 — 発現量に応じて希釈率を変える

DESIGN BUILD TEST LEARN
先に励起光で蛍光の強さを確認し、発現量に応じて希釈率を決める。 低発現の DivIVA は原液〜4倍、高発現の J23113 系は5〜20倍。アプライ量は全て統一。 IPTG 濃度と蛍光の相関を確認。ただし低濃度域では差が小さく読みにくい。 一律の希釈ではなく発現レベルごとに希釈率を変える。低濃度域の分解能は今後の課題。

このサイクルで確立したこと

  • in-gel 蛍光で発現量を比較する際は、破砕前に OD で菌体量を揃える。
  • 発現レベルに応じて希釈率を変え（低発現は原液〜4倍、高発現は5〜20倍）、検出レンジに収める。
  • この定量系は、サイクル1の局在観察と組み合わせることで「発現量と局在の対応」を論じる土台になる。

サイクル5 — 画像解析による局在の定量

目視から、数値へ

サイクル1で観察系が整い、局在を「見る」ことはできるようになった。しかし判定は依然として目視であり、観察者の主観が入る。そこで、大腸菌を自動でセグメンテーションし、片極／両極を機械的に判定する解析系の構築に取り組んだ。ここでも4回の反復を要した。
仮説 画像から大腸菌の輪郭を自動抽出し、蛍光フォーカスの位置を対応づければ、片極／両極の割合を客観的な数値として算出できる。
成功基準 IPTG 濃度に対して発現細胞率が単調に増え、片極の割合が減少・両極の割合が増加するという、予想される傾向を数値として検出できること。

反復1 — 古典的な閾値処理：分割できない

DESIGN BUILD TEST LEARN
輝度の閾値処理で大腸菌の領域を切り出す、最も単純な手法から始める。 明視野画像に古典的な閾値処理によるセグメンテーションを適用。 大腸菌をうまく分割できなかった。 密集した桿菌は単純な閾値では個体に分離できない。細胞形状を前提にした手法が要る。

反復2 — Omnipose：桿菌特化モデルで高精度に分割

DESIGN BUILD TEST LEARN
桿体細胞のセグメンテーションに特化した深層学習モデル Omnipose を使う。 Omnipose で明視野画像の大腸菌をセグメンテーション。 大腸菌自体のセグメンテーションはかなり高精度に行えた。 セグメンテーション自体は解決。次は蛍光と重ね合わせて局在を判定する段階へ。

反復3 — 明視野と蛍光の重ね合わせ：撮像ずれで全体判定が破綻

DESIGN BUILD TEST LEARN
セグメンテーションした細胞領域と蛍光画像を重ね、各細胞のどこに蛍光があるかをアルゴリズムで判定する。 明視野と蛍光画像を重ね合わせ、画像全体のセグメンテーション領域について片極・両極を自動判定。 撮像時のずれにより、焦点が合っている部分以外では細胞と蛍光が重ならず、全体の自動判定は不可能だった。結果も IPTG 濃度と発現細胞率が比例せず、明らかに不自然だった。 解析アルゴリズム以前に、画像そのものの位置ずれが致命的。全視野を一括で処理せず、ずれの小さい領域に限定する必要がある。

反復4 — 焦点の合う領域を切り抜き、人力判定で傾向を確認

DESIGN BUILD TEST LEARN
ずれの影響を受けない領域だけを使う。蛍光を持つ個体が多い領域を無作為に切り出し、そこで判定する。 該当領域を正方形で無作為に切り抜き、その範囲で片極・両極を人力で判定。 IPTG 濃度に比例して発現細胞が増え、片極の割合が減少し両極の割合が増加することを確認できた。 位置ずれの影響を排除できれば予想どおりの傾向が現れる。自動判定を全視野へ拡張するには撮像時の位置合わせ自体の改善が要る。

このサイクルで確立したこと／残る課題

  • 確立：Omnipose による桿菌セグメンテーションと、焦点の合う領域を切り抜いて判定する手順。これにより、IPTG 濃度に対する片極から両極への移行という Design の予想（Lin 2021）に沿う傾向を初めて数値として捉えられた。
  • 課題：明視野と蛍光の撮像ずれが自動判定を阻んでいる。全視野の自動定量には、撮像時の位置合わせ、あるいは取得後の画像レジストレーションが必要である。
  • 現在この解析パイプラインを整備中であり、完成後は過去に取得した画像も遡って解析し、Measurement として提出する。

サイクルをまたぐ学び

DBTL は各サイクルの中で閉じただけでなく、サイクル間で学びが循環した。代表的な流れを2つ挙げる。

「識別できない」がコンストラクトの設計要求を生んだ

サイクル2の反復2で接着による沈降は定量できたが、どの菌とどの菌が結合しているかは目視では区別できなかった。この学びが、サイクル3に「Intimin に蛍光タンパク質を融合した新しいコンストラクトを作る」という設計要求を返した。標識株ができたことで、反復4では凝集塊内の二色混在という決定的な証拠に到達している。

観察系の確立が、接着・定量・解析すべての前提になった

サイクル1で観察系を固めたことは、それ自体が独立した工学的成果であると同時に、サイクル2の二色蛍光観察、サイクル4の発現量と局在の対応づけ、サイクル5の画像解析すべての土台になった。観察できなければ何も主張できないという意味で、サイクル1はプロジェクト全体の律速だった。

現状と次のサイクル

  • 実験④（ペリプラズムでの CoilR/CoilE 相互作用）：内膜アンカーとペリプラズム提示体を構築中。架橋がペリプラズムで働き、距離が届くかを検証する。
  • 実験⑤（ΔLysM＋CoilE Intimin）：LysM を CoilR で置換、あるいは N 末端に CoilR を融合した Intimin を構築中。表層提示と接着能を保てるかを確認する。
  • 局在の完全自動定量：撮像時の位置合わせを改善し、全視野での片極／両極の自動判定を実現する。単極率・polarity index を数値指標として導入する。

DBTL としての総括

本プロジェクトの工学的な強みは、うまくいった結果よりも「うまくいかなかったときに、原因をどこまで遡って特定し、次の一手にどう変換したか」にある。接着が沈まなければ菌体密度と反応時間を上げ、コロニーが取れなければ鋳型を疑い、局在が見えなければ観察系そのものを作り直し、解析が破綻すれば画像そのものを疑った。

5つのサイクルはいずれも、失敗を起点に反復を重ねて到達点にたどり着いている。Design–Build–Test–Learn の反復そのものが、このプロジェクトを前に進めた。
